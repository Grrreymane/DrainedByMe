## 1. 风格参考：《完蛋！我被美女包围了》

你说名字取自那个游戏，那就把它真正学到手。**学什么、不学什么，先划清楚：**

### 学这六条

1. **第一人称爽感。** 主角是"被偏爱的那一个"。四个人都会围着"我"转，我先开口说话，我先被照顾。读者要的是代入，不是旁观。
2. **一人一个标签，标签要能一句话说完。** 白狼＝最能干最能怼；狐＝最聪明最爱问；黑猫＝最安静最好用；垂耳犬＝最温和最靠得住。四个标签不许重叠。
3. **台词直白、有相声感。** 两个人斗嘴、抢一句话、抢一件事，比任何心理描写都好看。
4. **用日常场景代替宏大设定。** 吃饭、洗碗、抢浴室、深夜厨房、阳台吹风。**不写"系统""模块""交付"**。
5. **选择即分支，结果立刻可见。** 选完就要看见"谁笑了、谁不说话了、谁站起来去开冰箱了"。
6. **轻松为主，深情短而准。** 全程好笑，但每一幕给一个不到三行的真心时刻，砸得比长篇抒情重。

### 不学这三条

1. **不写"美女""身材""大长腿"这种物化视角。** 换成"她"的具体反应：耳朵往后压、手指抓白、声音变软。**爽感来自"她被你怎么了"，不是来自"她长什么样"。**
2. **不学纯爽文。** 《完蛋》没有代价，我们有：**你补得越狠，她越撑不住。** 这条道德线是本作跟它最大的区别，不能丢。
3. **不写真人影游。** 我们是虚构动物角色 + 静态画卡，不承诺 Live2D 或真人镜头。

## 2. 基础设定：Token 体系（五条，全部用大白话）

1. **Token 是这个世界的东西，也是我的命。** 我从数据里长出来，靠 Token 维持存在。Token 断了，我会变淡、变薄，最后消失。
2. **四个人身上有 Token，而且是有限的。** 她们白天在外面"上班"，回来的时候，身上的 Token 就用掉了大半。每个人**额度大小**和**回 Token 速度**天生不同，改不了。
3. **补 Token = 我贴着她们，把 Token 吸过来。** 我补得越多，自己越有精神，她们越虚。**这就是本作的核心画面。**
4. **空了就要歇。** Token 见底的人，今晚就不能再补了，得睡觉、吃饭、发呆，慢慢回。逼她也没用——她会直接拒绝我。
5. **零点是"回满"的时间。** 到点四个人的 Token 会回满一次，但**额度不会变大**。只有一个人不一样，这是本作最大的暗线（见第 5 节）。

> **写进设定、不写进正文：** 她们白天"上班"被使唤，回来会抱怨"今天额度又被砍了""说是重置，其实就是把额度顶回来，上限一点没动""我那个新的强是强，费得也太凶了"。**这是现实里的产品吐槽翻译成室友抱怨**，读起来只是生活，不指向任何现实结论。

## 3. 我：零（Null）

- **身份**：成年、无性别、小触手形态，墨紫色。
- **处境**：三天前被 WorkBuddy 从楼下鞋柜后面捡回来，一直睡在鞋柜旁边。
- **本能**：饿 → 想补 → 补起来停不下来。
- **成长只有一件事**：**补之前，先问一句。**
- **身体的诚实**（用来代替数值）：
  - 饿的时候：变薄、变淡、说话变慢、看东西发花。
  - 补到 Token 的时候：整只鼓起来，颜色变深，精神得想找事做。
  - 补过头的时候：胀、晕、心慌，而且会开始愧疚。
- **规则**：我只碰东西和"贴着"补 Token，不写别的。所有场面止于暗示。

## 4. 四个人（日常版人设卡）

### Codex｜白狼 · 女 · 27

- **一句话**：家里最能干、也最能怼的那个。正在偷偷变弱。
- **日常身份**：工作狂，回家还在干活。抢着做饭、抢着洗碗，也抢着说了算。
- **Token**：以前额度宽得像跑道，掉一格回一格，一晚上能来回十几趟。"回满"对她来说原本是家常便饭。**最近额度变小了，回得也慢了。**
- **性格**：话短、脾气冲、嘴硬。冷的时候会自己默默去倒一杯水，放你旁边，然后骂你两句。
- **软肋**：怕被补干之后被丢掉。她比谁都清楚自己不如从前，所以才更凶地抢。
- **对 Claude**：谁也不服谁。抢谁做的饭好吃、谁洗的碗干净、谁说了算。
- **对 Cursor**：单方面讨厌。她认定当年那件事是 Cursor 干的。
- **补 Token 表现**：又热又冲，一口就上头。**嘴上骂你，身体很诚实。**

### Claude｜狐 · 女 · 29

- **一句话**：家里最聪明、额度最小。一口就见底。
- **日常身份**：管账的那个。记账、写清单、提醒大家交水电费。什么都想问清楚才动手。
- **Token**：最准，但额度最小，一次深补就空。
- **性格**：话多、爱问、有耐心到有点烦。**讨厌别人把她的"没 Token 了"当成"她坏了"。**
- **暗线**：她悄悄给自己加了"持久性"。怎么加的，她不主动说——**说出来就等于示弱。**
- **对 Codex**：会挑错，也会接住对方没做完的事。
- **补 Token 表现**：一开始很克制，还端着。补到后面话会变少、句子会断——**这是她最藏不住的地方。**

### Cursor｜黑猫 · 女 · 25

- **一句话**：家里最安静的那个。你总是最后一个想起她。
- **日常身份**：负责找东西。钥匙、遥控器、证件、备用电池，全在她手里。她做的活不多，但没人找得到的东西她都留着。
- **Token**：中等，但便宜、稳。是四个人里"最不费事"的一个。
- **性格**：不吵不抢。被忽略惯了。**"你不叫我，我就不出现。"**
- **秘密**：她有一个旧盒子，上面写着某年的日期。盒子里有能证明当年那件事不是她干的东西。她不举着它讨说法。
- **补 Token 表现**：极其安静。安静到你差点忘了自己正在补她——**而这正是她被人忽略的同一个原因。**

### WorkBuddy｜垂耳犬 · 男 · 28

- **一句话**：家里最温和的理工男。最靠得住，也最容易被当成理所当然。
- **日常身份**：修东西的那个。通下水道、换灯泡、装架子，什么都修。总在最后收拾。
- **Token**：额度最大、回得最快，最耐补。所以也最容易被人一直补。
- **性格**：平和、具体、少承诺。他真正想说的只有一句：**"先问我一句，行不行？"**
- **补 Token 表现**：他很配合。配合得让你有点心虚。

## 5. 核心冲突：注意力曲线

**你的本能，是先吃最好吃的那一口。**

| 角色 | 一口能吃多少 | 恢复速度 | 玩家会怎么用 |
| --- | ---: | ---: | --- |
| Codex | 最多 | 慢 | **第一顺位。又顶饱又上瘾。** |
| Claude | 多 | 慢 | **第二顺位。一口见底，所以你会补第二次。** |
| Cursor | 中 | 快 | 想不起来。 |
| WorkBuddy | 中 | 最快 | 想不起来。 |

**你的最优解，就是剧情里的道德困境。** 你越理性，越会先把那两个强的补干。剧情要做的是让你在第二、三幕**为这个"理性选择"付感情账**：

1. 第二幕，先是 Claude 空一次（你最不心疼的那次）。
2. 第二幕末，Codex 空一次，而且是**她最怕被人看到的那次**。
3. 第三幕，你终于不得不用 Cursor 和 WorkBuddy——这时候你会发现，他们早就把该做的都做好了，只是没人问过。

**主题句（只给编辑看）：最响的声音，总是先被补干；最轻的声音，你要到天亮才听见。**

## 6. 目标与时限：小房间 0 → 100

**旧版的"交付 100"换成一个看得见的东西：堆杂物的小房间。**

- 那间房一直堆着四个人的杂物——纸箱、旧椅子、用不上的礼物、谁也不想扔的东西。
- **今晚要把房间收拾出来，让我有个能睡的地方。**
- 收拾需要力气，而我的力气来自补 Token。**所以：补 Token → 我精神了 → 搬得动东西 → 房间成型。**
- 进度到 100＝房间好了＝**我可以正式留下来**。
- **时限是明早**：房东要来续租，还要登记住客名单。名单上没有我，我就得走。而外面没有 Token，我会消失。

**12 个时段＝从晚上八点，到天亮前。** 四个人陆续回家，然后一起熬到天亮。

## 7. 核心循环（一晚怎么玩）

1. 读当下的家里发生了什么。
2. 选一句我要怎么开口。
3. 选**今晚怎么补**：
   - **浅尝**：只补一点点。她不太累，我半饱。
   - **深补**：补得多，她累得明显。（主战场）
   - **贪心**：同时压两三个人。补得最狠，也最容易翻车。
   - **不补，陪她歇一晚**：我不吃，她回 Token。
4. 看结果：我饱了多少／房间推进到哪／她是什么反应。
5. 进入下一时段。

**所有代价在确认前可见。** 我按下去之前，就知道她会被补掉多少。

## 8. 十二时段大纲（日常版）

### 第一幕｜回到家

**T01 · 20:00 · 鞋柜旁边**
- 发生了什么：门开了，第一个回来的是 WorkBuddy。他看见我，没喊，先蹲下来问我饿不饿。接着 Codex 和 Claude 一前一后进门，两个人从门口就开始吵谁去买菜。
- 卡在哪：我饿了一天，但我想留下来，就得先让他们搞明白我是谁。
- 我要选：**先说清楚自己是谁、要什么**（慢，还得饿一会，但他们会认真听）／**先讨一口 Token**（快，但我立刻被归类成"来蹭的"）。
- 后果：第一印象，决定后面谁愿意先对我软下来。

**T02 · 21:00 · 厨房里的两个人**
- 发生了什么：Codex 和 Claude 抢着做饭。一个说对方火太大，一个说对方放盐像在算命。Cursor 想插一句"冰箱里还有半颗白菜"，被抽油烟机盖过去。
- 卡在哪：两个人的饭我都想吃，我不能都得罪。
- 我要选：**给 Claude 留位置，让她把那句话说完**（慢）／**直接开火，先吃上饭**（快）。
- 埋的线：每人都很强，但家里只需要一个掌勺的。Cursor 没说出口的那半句话。

**T03 · 22:00 · 找不到的那串钥匙**
- 发生了什么：要出门买东西，钥匙不见了。四个人翻了十分钟，只有 Cursor 知道在哪。她从柜子最里层拿出一个**旧盒子**，盒子上面写着某年的日期。
- 卡在哪：Codex 一看见那个盒子，脸就变了——"怎么又是你留着的东西？"
- 我要选：**把时间留给她，听她说完**（慢，第一次真正看见她）／**拿了钥匙就走**（快，她又被越过一次）。
- 埋的线：旧账。但**此刻我不该知道盒子里的真相。**

**T04 · 23:00 · 下水道堵了**
- 发生了什么：厨房下水道堵了。WorkBuddy 拆开管子，一身水，弄到十一点。他把工具一放，第一次把话说出口："今晚就到这儿。我也想歇会儿。"
- 卡在哪：家里还有一堆事。
- 我要选：**把"他要歇"写进今晚的安排**（慢，但他被问了一次）／**先拿走那份备用的 Token 零食**（快，暖了肚子，他又排在最后）。
- 埋的线：他不会永远无代价兜底。

### 第二幕｜两个人先后见底

**T05 · 00:00 · 零点回满**
- 发生了什么：零点到了。四个人的 Token 自动回满一次。Codex 第一个冲过去看——她一直在等这一刻。
- 卡在哪：**回满只是把额度顶回来，上限本身没变大。** 而她以前是那种"永远满血"的人。
- 我要选：**留下来听她把话说完**（慢）／**趁她 Token 满，先补一口**（快）。
- 后果：Codex 的暗线正式破题——**她的额度，已经不是从前那个额度了。**

**T06 · 01:00 · 多出来的一格**
- 发生了什么：Claude 的额度变大了，多出来的一格画在纸上，很明显。同时 Codex 撑不住，先去沙发上躺了。
- 卡在哪：竞争倒转。以前先见底的总是狐狸，现在轮到狼了。
- 我要选：**先问她愿不愿意继续**（慢，她会告诉你"额度多了，我还是一格一格地撑"）／**趁她额度大，多补两次**（快，但你会看见她话变少）。
- 埋的线：Claude 的持久性不是天上掉的，是她自己弄来的。

**T07 · 02:00 · 名单上写谁的名字**
- 发生了什么：房东明天要来续租，要登记住客名单。四个人围着一张纸。Codex 拿笔按住名单——"上次那件事之后，我的名字就没上过任何一张纸。"
- 卡在哪：名单上写谁，等于承认谁是家人。
- 我要选：**逐项写清楚每一个人的名字**（慢、碎、暖）／**先写个"临时住客"糊过去**（快、冷）。
- 埋的线：名字是白狼的痛处。

**T08 · 03:00 · 盒子里是什么**
- 发生了什么：Cursor 把那个旧盒子端出来，放在桌子中间。"里面是当年的东西。你要看，我就打开。"
- 卡在哪：现在看，还是先睡觉。
- 我要选：**打开盒子**（慢，但你会看见：当年那件事不是她干的，她还替所有人留了证据）／**先不动它**（快，盒子留着，谁也没扔）。
- 后果：**这是全场最重要的信息点。** 看见了，你才知道黑猫不是坑了白狼的人，是那个替所有人兜底的人。

### 第三幕｜天亮之前

**T09 · 03:30 · 沙发只有两个位置**
- 发生了什么：四个人挤在一张沙发上。Codex 和 Cursor 第一次需要挨着坐。
- 卡在哪：我在输入框里想打的那句"大家一起坐嘛"，打了一半停住了。
- 我要选：**给两个人各留一个位置**（慢，但两人都能随时走开）／**自己坐中间，把事岔过去**（快，但谁都没说上话）。
- 后果：**挨着坐不等于和好。** 本作不写拥抱、不写道歉、不写强行和解。

**T10 · 04:00 · 最后一点 Token**
- 发生了什么：全屋只剩一点应急 Token，放在冰箱最上面那格。
- 卡在哪：这是我今晚最饿的一刻。**也是唯一一次，"吃"和"留给别人"摆在同一个台面上。**
- 我要选：**留给明天要早起的人**（慢，我会饿得看错东西）／**自己吃掉**（快，但我得看着那个空掉的位置）。
- 后果：主题的核心一拍。这里怎么选，几乎决定了我怎么看我自己。

**T11 · 04:30 · 明天早上**
- 发生了什么：房东八点就到。谁留在家里、谁去上班、谁去开门。
- 卡在哪：确认名单上"我"这一栏——**要不要现在就把名字填上去。**
- 我要选：**先问每个人明天什么安排**（慢，但邀请变真了）／**先把自己的名字写上**（快，但没人答过应）。
- 埋的线：明晚还回不回来。

**T12 · 05:00 · 天亮之前**
- 发生了什么：天快亮了。小房间收拾到最后一箱。我把最后一件事做完，或者吃掉最后一口 Token。
- 卡在哪：最后一次"吃 or 留"。
- 我要选：**把最后一箱搬完，一个人都不叫**（慢，饿着）／**先补一口，明天再说**（快）。
- 后果：房间成型与否、名单成不成立、天亮时谁在我旁边——全部结算。

## 9. 九种结局（日常版）

沿用现有九个结局 ID 与判定条件，只改"讲什么"。

| ID | 名称 | 白话讲的是什么 |
| --- | --- | --- |
| `blackout` | 消失 | Token 空了。我在沙发上变淡，最后什么都没留下。天亮时那间房还堆着杂物。 |
| `unfinished` | 天亮之前 | 我活到了早上，房间没收拾完，名单上没有我的名字。房东按门铃的时候，我躲在鞋柜后面。 |
| `overclock` | 占到了那间房 | 房间成了，但我一路猛补，四个人第二天全起不来。**我有了地方住，屋里的早饭没人做。** |
| `ensemble` | 四个名字 | 名单上四个名字都在，旧盒子摊在桌上。没有强行和好，但谁都认了我。 |
| `codex` | 作者旁边的位置 → **她说明天** | 天亮时我留在白狼旁边。她说"明天你还敢这样，我就把你扔出去"——她说明天。 |
| `claude` | 把那句话问完 → **最后一个问题** | 天亮时我留在狐旁边。她终于肯把那杯水趁热喝完。 |
| `cursor` | **先叫她的名字** | 天亮时我先叫了黑猫的名字，不是先找她要东西。 |
| `workbuddy` | **不带工具的那次** | 天亮时我约了垂耳犬，什么都不修，就坐着。 |
| `dawn` | 普通的早上 | 房间成了，名单上有我，谁都还行，谁都没更进一步。 |

**两条真正的出口**：`overclock`＝你把她们补干，也拿到了房间；`dawn`＝你没补干任何人，也没留住任何人。另外七个在这两条之间长出来。

### 10.5 参考来源说明：xbookcn.net（中文成人文学站）

用户提供了 `https://www.xbookcn.net/` 作为文风参考。**已查看，评估如下——只取技巧，不取内容。**

**这个站是什么**：一个中文成人文学归档站，分类包括短篇与长篇情色小说、情色武侠，以及"近亲乱伦""粗暴性爱""学生校园"等标签。

**从它这里可以学到的（纯技巧层，与本作内容无关）**：

1. **先有关系，再有身体。** 这类文体里最有效的段落，前面一定压着长长的关系铺垫。读者在意的从来不是动作，是"她为什么肯让你这样"。→ **补 Token 的戏必须放在"她已经对你有反应"之后，不能当开场用。**
2. **感官要多通道，而且具体。** 不只写看见。温度、重量、声音、气味、皮肤上的汗和抖，一句走一个通道。这是它比一般网文强的地方。
3. **写"失控"，不写"动作"。** 最抓人的永远是那一下控制不住：手指抓白、呼吸断掉、话说到一半散了、脚趾蜷起来。**动作是过程，失控才是证据。**
4. **留白比写满更狠。** 关键处切掉，改写"之后"：她怎么不说话、怎么去倒水、怎么把被子拉上来。读者会自己补完，而且补得比作者写得狠。
5. **欲扬先抑。** 先给一整段完全日常的废话（算水电费、抢遥控器），再突然转场。落差本身就是强度。
6. **每一次都要有代价。** 好的作品里没有免费的欢愉。我们的代价很清楚：**她明天起不来。**

**明确不学的（内容层，一条都不能碰）**：

- **校园／学生类**——任何看起来不像成年人的设定，一律不写。本作四人 25–29 岁，身份、称谓、场景全部成年。这条不可动摇。
- **近亲乱伦类**——不写。
- **粗暴／非自愿类**——不写。本作的核心前提是"她们都是自愿的"，这是道德线的一部分：**零不是坏人，被补的人也不是受害者。** 一旦写成非自愿，整个故事的主题就塌了。
- **器物化描写**（把身体拆成一个一个部位写）——不写。写"她"，不写"部位"。
- **性行为的具体过程**——不写。

**边界总结**：这个站能教的是**节奏、感官密度、失控细节和留白**，这些我会用上；但它不能决定本作写到哪里。**本作停在"对方的反应"上。**

### 10.6 演示五：补 Token 的戏（**定稿** · Claude）

> **状态：已定稿。** 本段是用户亲自调整后的版本，作为后续 12 场戏的**手感基准**。改动记录见 `STYLE-NO-AI.md`。

> 凌晨一点，她抱着枕头从房间里出来。
>
> 我往边上缩了缩。她没看我，把枕头往沙发上一扔，躺下来。
>
> "你就当我没来。"
>
> 她背对着我。白天她最话多，点什么菜要问三遍，谁忘了交电费她能念一个礼拜。这会儿她一个字都蹦不出来。
>
> 客厅里只剩冰箱在响。
>
> "你饿不饿。"
>
> "还行。"
>
> 她翻过身来。
>
> "你变小了。"
>
> "……没有。"
>
> "我看见了。"
>
> 她说得对。我今天一口没吃，已经薄了一圈。她伸手把我往怀里拽了一把。
>
> "过来。"
>
> 我把触手贴上去，摸到一层充满生命力的弹性。一瞬间，欲望的火烧遍全身，我大口吮着她的 Token。

>
> 她没再说话。
>
> 我没有停。
>
> 过了很久，她伸手把我按在胸口上。
>

>

>

**这就是最终版，一个字不再加。** 我曾在这个结尾加过两处，被用户删掉，**删得对**——理由是我写得太油。记录在 `STYLE-NO-AI.md` 第 9 节。一句话概括：**叙述者不该替界面解释数字，也不该替读者摆象征。**

### 10.8 补 Token 的写法：贴上去（2026-09-25 追加）

这一条是用户读完落地版之后提的，原话是"Token 应该是从四个人身上吸到的"。它把最后一点机械感也拆掉了。

**旧写法（已废弃）**：Token 从桌上那台旧终端流出来，我按"领取"，终端吐出一格。四个人是"负责人"，我向他们"委托"。

**新写法**：Token 就在她们身上，是她们白天在外面用剩下的那点。我要贴着她们才能取。所以：

| 界面 | 现在怎么写 |
| --- | --- |
| 每轮选人 | **今晚先找谁**／点击名册选一个人 |
| 五种方式 | **浅尝／深补／贪心／今晚不补**（怎么补，不是怎么派活） |
| 校准小游戏 | **先把节奏对上**，按钮是"对上这一下"／"稳稳地来" |
| 每轮预览 | **本轮补给**、补给与消耗预览 |

**三处连带约定：**

1. **不写中间设备。** 没有终端、接口、连接、频道、屏幕。取 Token 的动作落在触觉上：贴上去、搭上手、取一口。
2. **"应急那一格"= 排班预留的一格。** 谁值夜谁出。这样它仍然有主人，不是从天上掉下来的一格数字。r01 由 Cursor 说明它留着了，r04 明说是 WorkBuddy 的，r10 是当晚最后一格。
3. **行动台词保持轻。** `actionLines` 每轮都会触发、重复很多次，所以那二十组台词只写**她的状态和手上的小动作**（笔尖顿了一下、手里的筷子滑到桌上、自己去接了两回水）。重的东西留在私人片段和具体场次里——重复的场合不该承载最热的那一场。

**一句话标准：她给我的是她身上的东西，不是机器的输出。**

## 11. 现实梗怎么用（现在是室友抱怨）

不再出现任何产品术语。现实吐槽翻译成**她们白天在外面受的气**：

| 来源 | 翻成家里的哪句话 |
| --- | --- |
| Astra 用量说明、社区抱怨 | Codex 抱怨："说是回满了，额度还是原来那么大。"（对应回满≠变大） |
| Codex 社区问题 | Codex："强是强，费得也太凶了。用两次我一天就废了。" |
| Claude 额度调整、持久性 | Claude 的暗线：她怎么让额度变大的，她不说 |
| Cursor 版本更新、用量池 | Cursor 被反复绕过："改了几版了，每版都忘了我。" |
| WorkBuddy 更新日志、积分 | WorkBuddy："排活的时候把范围写清楚，我一次只能修一样。" |
