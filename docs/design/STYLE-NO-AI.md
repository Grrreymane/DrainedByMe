# 去 AI 味手册

> 用途：本项目的正文写作自查。**只看结构，不看词藻。**
> 起因：用户指出文笔仍有 AI 味。本文件把我自己写的句子拆开，标出假在哪里，并给出人怎么写的对照。
>
> **用词（2026-09-25 已确认）**：资源＝**Token**，容量／余量＝**额度**。本文件正文里的"魔力""杯子"若仍有残留，一律按此替换；以 `REWRITE-OUTLINE-v3.md` 第 10.7 节用词表为准。

## 0. 结论先行

**AI 味不是"用词问题"，是"结构问题"。** 换同义词、加口语词、删几个"仿佛"，都没用。

真正的病根是**太干净**：

- 每一段都要升华一下、收一个金句。
- 每一组句子都要对仗。
- 每一个潜台词都要解释给读者听。
- 每一句都差不多长。
- 每一个细节都"有用"，都在服务主题。
- 每一句对白都完整、都聪明、都带潜台词。

**人类写作的真相是：有毛边。** 会跑题、会说废话、会硬切、会写一个跟主题毫无关系的细节，只因为生活里就是有这个东西。

**所以自查的方法很简单：把这段话里的"干净"找出来，然后弄脏它。**

## 1. 十二条自查（每条都用我自己写过的句子）

| # | 症状 | 我写的（假） | 假在哪 | 人怎么写 |
| --- | --- | --- | --- | --- |
| 1 | **段末升华** | "我后来才明白，她说明天的时候，其实是在说：你别走。" | 作者跳出来替读者总结。这是最典型的一条，我几乎每分钟犯一次。 | 直接删。停在她说的那句"明天"，下一段硬切。读者自己会懂。 |
| 2 | **排比对仗** | "她平时话那么多，那么爱问，那么喜欢把每一件事都捋清楚。" | "那么……那么……那么……"是机器节奏。 | "点什么菜要问三遍，谁忘了交电费她能念一个礼拜。"——换成具体的事，数量变成两件。 |
| 3 | **解释潜台词** | "她没有躲开。"（紧跟"我把触手贴上去"） | 太顺、太对、太有设计感。 | 不写"她没有躲开"。写她把枕头往里挪了挪。 |
| 4 | **节奏太匀** | 通篇三到五句一段，句长接近。 | 像排版过的。 | 长短乱来。一句话一段。有时候一个词一段。 |
| 5 | **对白太聪明** | "'你撒谎的时候会变小。'她翻了个身，看着我，'我看得出来。'" | 一句 18 个字，还带机锋和动作提示。真人不会这么说话。 | "你变小了。" / "……没有。" / "我看见了。" 三句，一共 13 个字。 |
| 6 | **比喻用力过猛** | "像有人把一整壶刚烧开的水从嗓子眼里灌下来。" | 太努力了。这是"文学腔"，不是生活。 | "烫。" 一个字段。顶多加一句"头皮发麻"。 |
| 7 | **细节太有用** | "房间里只有冰箱的声音。" | 冰箱声是氛围道具，专门用来营造气氛的。 | 写蚊子。写一只飞一会儿停一会儿的蚊子。**没用，但真实。** |
| 8 | **情绪报备** | "她的心跳得很乱，很久才平下来。" | 勉强可以，但"乱"是形容词式报备。 | 留着，但换成"心跳先是乱，后来一点点慢下去"——写过程，不写结论。 |
| 9 | **破折号装文学** | "很烫。比我想象的烫得多，也比我想象的多——她的额度明明只有那么一点，可她给我的时候，一点都不吝啬。" | 一个破折号里塞了三层意思，还带抒情。 | 拆成三句，而且是短句："我以为她额度就那一点，得省着给我。她没有省。" |
| 10 | **不敢写糙的** | 整段没有一个粗口、一句废话、一次跑题。 | 太礼貌。 | 让她骂一句，让她答非所问，让叙述者插一句没用的吐槽。 |
| 11 | **过渡太顺** | 每段之间都用时间或动作接上（"过了很久""等我再看过去"）。 | 缝得太密。 | 硬切。上一段在沙发上，下一段直接就是"第二天她八点醒"。 |
| 12 | **身体只有一种感觉** | 只写"烫""抖"。 | 感官贫。 | 加上痒、酸、麻、干、冷。写脚背上晾着的凉。 |

## 2. 同一场戏：AI 版 vs 人味版

左右对照，改动点用括号标出。

| AI 版（我原来的写法） | 人味版 |
| --- | --- |
| 她说要在客厅睡，因为房间太吵。我信了。 | （**删掉"我信了"这种机锋**）她没在客厅睡。她回房间了，然后又出来了。 |
| 凌晨一点，她抱着枕头过来，说："你就当我没来。" | 凌晨一点，她抱着枕头出来。"你就当我没来。" |
| 房间里只有冰箱的声音。 | （**加没用的细节**）沙发底下有只蚊子，嗡嗡的，飞一会儿停一会儿。 |
| "……你饿吗？"她忽然问。 | "你饿不饿。" |
| "还行。" | "还行。" |
| "你撒谎的时候会变小。"她翻了个身，看着我，"我看得出来。" | （**对白砍短**）"你变小了。" / "……没有。" / "我看见了。" |
| 我凑过去，把触手的尖端贴在她的锁骨下面。她没有躲开。 | （**不写"没有躲开"**）她伸手，把我往里拽了一把。"过来。" |
| Token 过来的第一秒，她就咬住了下唇。 | 触手搭上去的时候，她先抖了一下。 |
| 很烫。比我想象的烫得多，也比我想象的多——她的额度明明只有那么一点，可她给我的时候，一点都不吝啬。 | （**拆短句、去抒情**）烫。 / 我以为她额度就那一点，得省着给我。 / 她没有省。 |
| "你慢——"她说到一半，停了。 | "慢、慢点。" / 她声音不对了。 |
| 她平时话那么多，那么爱问，那么喜欢把每一件事都捋清楚。现在她一个字都捋不出来。 | （**排比换成具体的事**）她平时话最多。点什么菜问三遍，谁忘了交电费能念一个礼拜。 / 这会儿没声了。 |
| 她的手指陷进沙发的布面里，指甲刮出很轻的响。脚背绷起来，又慢慢松开。 | 手指掐进沙发垫，脚背绷在那儿，晾着。（**"晾着"＝凉，加了触觉**） |
| 过了很久，她伸手，把我的触手按在自己心口上，说："就这样，待一会儿。" | 过了很久，她把我按在胸口上。"就这样。" |
| 她的心跳得很乱，很久才平下来。 | 她的手慢慢松开。心跳先是乱，后来一点点慢下去。 |
| 第二天早上，她八点才醒。桌上那杯水，凉透了。 | （**这段本来就对，保留**）第二天她八点醒。桌上那杯水是头天晚上倒的，一口没动。我伸过去碰了碰杯壁。 / 凉的。 |

**注意最后一行**：那句"凉透了"是我原稿里唯一不 AI 的句子——因为它**没有解释**。它只陈述了一个物理事实，剩下的交给读者。整篇应该都是这个手感。

## 4. 人味版：厨房那场（T02）

日常戏比补 Token 的戏更容易 AI 味，因为日常最怕"每一句都在推进剧情"。这场戏唯一的任务是：**让人看见 Cursor 说话没人听。**

>

>
> "冰箱里还有半颗白菜。"
>
> 抽油烟机声音太大。没人听见。
>
> "半颗也行。"
>

>
> 她把门带上了。
>

## 5. 写完必过的检查表

写完全文，逐条过一遍：

- [ ] 每段结尾停在**动作**或**废话**上，不许停在一句道理上。
- [ ] 搜"其实""原来""才明白""说明""仿佛""这就是"——出现即查，八成在解释。
- [ ] 出现连续三个同结构句子 → 拆掉一个。
- [ ] 连续三句长度接近 → 砍掉中间那句，或者把其中一句压成一个词。
- [ ] 对白里单句超过 25 个字 → 拆开或删掉。
- [ ] 每场戏至少留一个**没用**的细节（蚊子、外卖单、广告短信、谁家空调在滴水）。
- [ ] 每场戏至少有一处**硬切**，不要每段都用时间词接缝。
- [ ] 全篇至少出现一次粗糙的东西：粗口、口水词、跑题、答非所问。
- [ ] 禁用表达复查：仿佛、总而言之、令人窒息的张力、不是……而是……、不禁、忍不住。

**一句话记住：读者不需要我替他感动，我只需要把杯壁是凉的这件事告诉他。**

## 6. 第二次修正：人味版反而更差（重要）

**用户反馈：第 3 节的"人味版"不如第 2 节被标为 AI 的初版。**

这是有效反馈，不是口味问题。复盘出四个具体错误：

### 错误一：把"短"当成了"不表演"

初版的病是**通篇匀称的中长句**。我的解药是**通篇匀称的短句**。

**病灶没动，只是换了个节拍器。** 一律写短、一律一句一段，本身就是一种新的机械感。

**修正**：段落长短要**服从此刻的呼吸**，不是服从风格。

| 情境 | 句子形态 |
| --- | --- |
| 平缓、铺垫 | 可以长，可以带废话，可以描述环境 |
| 加速、紧张 | 变短、变碎，主语开始消失 |
| **高潮、最热处** | **必须连贯，一口气写下去。不要一行一句。** |
| 事后、收束 | 重新放慢、拉长，给一点私人化的叙述 |

**"最热的地方逐行断开"是第 3 节最大的失分。** 越连贯越有压迫感。

### 错误二：删掉"下结论"，也顺手删掉了"给情绪"

这两件事必须分开：

- **替读者下结论** → 删。
  - ❌ "其实是在说：你别走。"（替读者把潜台词翻译成结论）
- **给读者情绪** → 不能删，要用别的方式补回来。
  - ✅ "后来我才知道，她那天晚上本来是要回房间的——客厅的沙发她嫌吵，这话她说过不止一次。"

**"后来我才知道"本身不是问题，问题在后面接什么。**
- 接**抽象结论**（"其实是在说你别走"）＝ AI 味。
- 接**具体事实**（"她本来要回房间"）＝ 合法，而且是给情绪最有效的方式——**用一个事后才知道的小事实，代替一句总结。**

这是本次最大的收获：**情绪不靠结论，靠一个更晚才被知道的、具体的事实。**

### 错误三：没用的细节必须"属于某个人"

第 3 节加了"沙发底下的蚊子"。这只蚊子是**通用噪音**——跟谁都搭，等于零，还分散注意力。

**修正**：每一个"没用的细节"都要能挂到某个具体人物身上。

| 通用噪音（删） | 属于人物的细节（留） |
| --- | --- |
| 沙发底下的蚊子 | Claude 头天晚上倒了没喝的那杯水 |
| 冰箱在响 | Codex 掰直的回形针 |
| 窗外的车声 | Cursor 手里那串别人找不到的钥匙 |

### 错误四：把技巧写成了新教条

检查表里"每场戏至少一处硬切""一句话一段"这类条目，是**过火**的。技巧是备选工具，不是强制配额。用不用，看这一段需不需要。

### 修订后的核心原则（四条）

1. **节奏服从内容，不服从风格。** 该长的长，该碎的碎，**高潮必须是连贯的一口气**。
2. **删结论，补事实。** 不解释潜台词，改用"更晚才知道的一个具体事实"来承载情绪。
3. **细节必须有人格归属。** 挂不到人身上的细节，删掉。
4. **技巧是工具，不是教条。** 不设配额。

保留初版的**热度和连贯**，只摘掉真正的 AI 病灶（段末升华、破折号抒情、对白机锋），并用"后来才知道的具体事实"替代总结。

### 我试过、被用户删掉的两处（重要记录）

我在这段里加过两处，用户直接删了。理由是"**理由或许对，但表达出来很油腻、很 AI**"。**这个判断是对的**，值得记下来——因为它是本项目最容易再犯的错。

| 我加的 | 油在哪（机制） |
| --- | --- |
| "我以为她的额度就那么一点，得省着给我。**她没有省。**" | 这是个**设计好的 A/B 反转**：先立一个"我以为"，再用独立成段的"她没有省"把它打翻，鼓点敲得太准。而且"得省着给我"是叙述者在**替她解释动机**——已经带上了自我感动的味道。 |
| "我伸过去碰了碰杯壁。／**凉的。**" | 这是**摆拍**。那个动作没有任何理由存在，它唯一的作用是让我说出"凉的"这两个字。而"凉的"独立成段，是在冲读者使眼色："你看我没解释。" |

**两处的共同病根，一句话：它们都在"工作"，而且看得见在工作。** 读者不需要看懂技巧，读者只会觉得有个人站在旁边。

### 换来的原则（写进第 10 节）

- **不替界面解释数字。** 这是游戏，额度条就在屏幕上。正文里再解释"她额度小"，等于把玩家已经看见的东西又说一遍。
- **不替读者摆象征。** 一个动作要想不出"她／他为什么非做不可"，就不要写。
- **不抢时机的活。** 要给的代价，交给机制和后面的场次，不要在她刚睡着的时候由叙述者总结。

### 保留的唯一一处修正

`大口地吸允` → `大口吮`。**"吸允"是错字**，正确写法是**吸吮**（shǔn）。这处与风格无关，属于用字错误，已改。

### 一个待你确认的小点

`这会儿她**咋**一个字都蹦不出来`——"咋"是北方口语，会给**叙述者**定一个口音。它本身很有味道（比"一个字都说不出来"更像人话），但**一旦用了，全篇叙述者的口音就得统一**，不能只在这一次出现。要留，就把它写进人物腔调规则；要稳，就换成"一个字都蹦不出来"。建议**留**。

## 10. 新增原则：叙述者不干活（2026-09-25）

前面九节讲的是"句子怎么不表演"。这一节是更狠的一层：**别让叙述者去干本来就该别人干的活。**

三条：

1. **不替界面解释数字。** 这是游戏。额度、疲劳、进度都在屏幕上。正文再写一遍"她额度很小"，玩家只会觉得被当傻子。
2. **不替读者摆象征。** 判断方法很土但有效：**这个动作，她／他为什么非做不可？** 想不出来，就是我在摆道具。
3. **不抢时机的活。** 代价要在它开始"碍事"的时候出现（第二天早饭没人做、她那栏进度没动、谁在门口嘟囔一句），**不要在她刚睡着的时候由我总结出来。**

### 为什么"照规则改"会失败

我这次是按**自己写的**去 AI 味规则（"一句话一段""结尾停在动作上"）去改的，结果更油。原因是：

> **规则是形状，不是动机。** 照形状描一遍，出来的还是表演——只是从"排比式表演"换成了"克制式表演"。

真正的判断标准只有一条：**这句话是不是有人非说不可。**
